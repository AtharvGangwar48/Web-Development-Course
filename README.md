## 📖 About This Repository

This repository is a complete record of my journey through the **Delta 3.0 Full-Stack Web Development** course by **Apna College**. It contains every concept, practice question, mini-project, and full project I built — from writing my first HTML tag to deploying full-stack MERN applications with databases.

---

## 🗂️ Course Curriculum

### 🌐 HTML
> The foundation of every web page.

- Semantic elements, forms, tables, media tags
- Practice questions across 3 levels
- Projects: Recipe Page, Resume, Product Review Page, FAQ Page, Wikipedia-style Info Page

---

### 🎨 CSS
> Making the web beautiful.

- Box Model, Flexbox, Grid, Positioning, Z-index
- Animations, Transitions, Transforms
- Media Queries & Responsive Design
- Bootstrap (Forms, Grid, ID Cards)
- **Mini Project:** Pet Adoption Page
- **Major Project:** 🎵 Spotify Clone

---

### ⚡ JavaScript
> Bringing the web to life.

| Topic | Description |
|---|---|
| Core Concepts | Variables, loops, functions, arrays, objects |
| Advanced JS | Closures, `this`, Promises, Async/Await, Callbacks |
| DOM | Selecting, manipulating, and creating elements |
| ES6+ | Arrow functions, Destructuring, Spread/Rest operators |
| OOP | Classes, Inheritance, Factory Functions, Prototypes |
| APIs | Fetch API, sending requests, working with free public APIs |
| **Mini Projects** | Simon Says Game, To-Do List, Random Color Generator, Tic-Tac-Toe |

---

### ⚛️ React
> Building modern UIs with components.

- JSX, Components, Props
- CSS Modules
- Project: Product Showcase App (built with Vite)

---

### 🟢 Node.js
> JavaScript on the server.

- Node modules, file system
- Built-in & custom modules
- npm & package management (Figlet, Math libs)

---

### 🚂 Express.js
> Fast, minimal web framework.

- Routing, middleware, error handling
- EJS templating engine
- RESTful APIs (CRUD operations)
- Cookies & Sessions
- Express Router

---

### 🍃 MongoDB
> NoSQL database for modern apps.

- CRUD with Mongoose
- Schema & Models
- Data relationships (One-to-Many, Many-to-Many)
- Combining Mongo + Express for full-stack apps

---

### 🛢️ MySQL
> Relational databases.

- SQL queries & schema design
- Integrating MySQL with Express + EJS
